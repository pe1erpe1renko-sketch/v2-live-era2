# Era Alive

Создай лендинг на React + Tailwind для сервиса Live Era — нейросеть оживляет фотографии: пользователь загружает снимок и получает короткое видео.

Сейчас сделай только: дизайн-систему, шапку, первый экран и футер. Остальные секции не создавай — добавим их следующими шагами.

Дизайн-система

Стиль — технический минимализм: сетка, тонкие границы, много воздуха, крупный лёгкий заголовок, служебные подписи капслоком. Ощущение точного прибора, а не яркого маркетингового лендинга.

Пропиши эти токены в `tailwind.config` и используй только их, никаких произвольных цветов:

```

bg:      #FAFAFA   // фон страницы

surface: #FFFFFF   // карточки и панели

rule:    #E4E4E7   // основная граница, 1px

rule2:   #F4F4F5   // светлая граница, внутренние делители

ink:     #27272A   // основной текст

ink2:    #71717A   // вторичный текст

ink3:    #A1A1AA   // подписи, мета, служебное

gold:    #8A6A2F   // главная кнопка, фон под белым текстом

gold2:   #B08D57   // точки, тонкие линии, иконки, частицы

gold3:   #F5EEE0   // мягкая заливка, бейджи, hover

```

Типографика

Шрифт только один — Inter, подключи с Google Fonts. Второго шрифта в проекте быть не должно.

Три роли:

display — clamp(40px, 6vw, 72px), weight 300, line-height 1.0, letter-spacing −0.05em

body — 15px, weight 400, line-height 1.6, цвет `ink2`

label — 12px, weight 500, uppercase, letter-spacing 0.14em, цвет `ink3`

Роль label — это подпись стиля. Используй её для всех служебных надписей: заголовков-надстрочников, подписей к цифрам, мета-строк.

Сетка и отступы

Базовый ритм 4px. Разрешённая шкала: 4, 6, 12, 16, 24, 32, 48, 64. Других значений не вводи.

Контент ограничен по ширине, макет строится по сетке. Отступ секции — 64px по вертикали (32px на мобильном), padding карточки — 32px.

Формы и глубина

Радиусы только три: 6px для кнопок, полей и мелких элементов, 16px для крупных карточек и панелей, 9999px для бейджей и пилюль. Ничего между.

Тени только две:

карточка: `0 1px 2px rgba(0,0,0,0.05)`

панель: `20px 0 40px rgba(0,0,0,0.03)`

Поверхности читаются как приподнятые: сначала тень, границы её только подчёркивают.

Приём для главной карточки формы: оберни её во внешнюю оболочку с нулевым padding и нулевым радиусом, а фон оболочки задай двумя линейными градиентами `linear-gradient(to right, #E4E4E7 1px, transparent 1px)` и `linear-gradient(#E4E4E7 1px, transparent 1px)`. Внутреннюю поверхность вложи с радиусом 16px. Получится тонкая рамка-волосок, а не плоская обводка.

Ни одного градиента в заливках. Золото — только акцент: кнопка, точки, тонкие линии, иконки. Никаких крупных золотых плашек.

Иконки

Набор Solar, линейный стиль (через iconify, префикс `solar:`). Толщина штриха одинаковая везде, цвет `gold2` или `ink3`.

Движение

Минимальное и медленное. Длительность 2000мс, easing `cubic-bezier(0.4, 0, 0.6, 1)`. Появление секций при скролле — через GSAP ScrollTrigger, мягкое, без сдвигов больше 16px. Уважай `prefers-reduced-motion`: при нём отключай всю анимацию, включая канвас.

Компонент `SectionLabel`

Понадобится дальше на каждой секции: круглая точка 6px цвета `gold2` + текст в стиле label. Например: `● СНИМОК → ВИДЕО`

Шапка

Высота 72px, фон `bg`, снизу граница 1px `rule`, липкая при скролле.

Слева: круглая метка 28px с обводкой 1px `gold2`, внутри маленький золотой квадрат, рядом текст «Live Era» — Inter 300, 18px.

По центру: `Сценарии ▾`, `Нейросети ▾`, `Примеры`, `Цены`, `Блог` — 14px, цвет `ink2`, при наведении `ink`. Выпадающие меню — заглушки.

Справа: текстовая ссылка «Войти» и кнопка «Создать видео» — фон `gold`, белый текст, радиус 6px, padding 12px 24px.

Крайний правый угол: подпись в стиле label — `RU · БЕЗ VPN`

На мобильном: лого слева, кнопка «Создать» справа, остальное — в бургер-меню.

Первый экран

Две колонки: слева 42%, справа 58%. Между ними вертикальная граница 1px `rule`. На мобильном складываются в одну, правая уходит вниз и получает высоту 60vh.

Левая колонка (padding 64px, на мобильном 32px)

`SectionLabel` с текстом `● СНИМОК → ВИДЕО`

Заголовок H1 в стиле display, в две строки разного цвета:

строка 1, цвет `ink`: Оживить фото бесплатно

строка 2, цвет `ink3`: снимок станет живым видео

Подзаголовок в стиле body, максимальная ширина 460px:

«Kling 3, Sora, Veo и Seedance — в одном окне. Загружаете снимок, через пару минут забираете MP4 без водяных знаков. Русский интерфейс, оплата картой РФ, VPN не нужен.»

Карточка формы: фон `surface`, радиус 16px, padding 32px, тень карточки, обёрнута в градиентную рамку-оболочку из раздела «Формы и глубина».

Сверху два таба: Фото в видео (активный) и Видео из текста. Активный — фон `gold3`, текст `gold`, снизу линия 2px `gold2`. Неактивный — текст `ink3`.

Зона загрузки: пунктирная граница 1px `rule`, радиус 6px, padding 32px, по центру. Иконка `solar:gallery-add-linear` цвета `gold2`, под ней «Перетащите снимок или выберите файл» (14px, `ink`) и «JPG или PNG» (12px, `ink3`). При наведении граница `gold2`, фон `gold3`. Загрузка должна реально принимать файл и показывать имя после выбора.

Поле ввода, радиус 6px: placeholder «Опишите движение — или оставьте пустым».

Кнопка на всю ширину: фон `gold`, белый текст 15px, радиус 6px, padding 16px. Текст: Оживить снимок — первый ролик бесплатно. При наведении фон темнеет до `#6B5220`.

Под кнопкой строка в стиле label: `БЕЗ VPN · РУССКИЙ ИНТЕРФЕЙС · КАРТА РФ`

Ниже формы — панель-сводка: граница сверху 1px `rule`, padding 24px 0.

Две колонки:

Слева: подпись label `МОДЕЛЕЙ В ДОСТУПЕ`, под ней число 10 — Inter 300, 36px, цвет `ink`.

Справа: подпись label `СТАТУС`, под ней точка 6px `gold2` + текст `ПЕРВАЯ ГЕНЕРАЦИЯ БЕСПЛАТНА` в стиле label, но цветом `ink`.

Под ними делитель 1px `rule2`, ниже строка: слева бейдж-пилюля (радиус 9999px, фон `gold3`, текст «Реставрация включена» 12px цвета `gold`, padding 6px 12px), справа `MP4 · БЕЗ ВОДЯНЫХ ЗНАКОВ` в стиле label.

Правая колонка — поле частиц

Фон `bg`. На всю площадь колонки — `<canvas>` с дот-матричным полем частиц. Реализуй на canvas 2D, не на WebGL.

Точки радиусом 1–1.5px цвета `gold2`, разреженные, шаг сетки около 22px, с лёгким случайным смещением.

Мягкое затухание к краям колонки: прозрачность точки падает по мере удаления от центра.

Медленное «дыхание»: прозрачность и размер точек пульсируют волной, идущей от центра, полный цикл 2000мс, easing `cubic-bezier(0.4, 0, 0.6, 1)`.

Точки слегка сносит за курсором — смещение не больше 6px, с плавным возвратом.

Плотность выше в центральной круглой области, к периферии реже — поле должно читаться как размытый круг.

При `prefers-reduced-motion` канвас не запускается, вместо него статичная CSS-сетка из точек `#EDEAE3` с шагом 22px.

Поверх канваса, по центру — две фотокарточки рядом, слегка перекрывающие друг друга, обе с белой рамкой 12px, границей 1px `rule`, радиусом 6px и тенью карточки:

Левая: чуть ниже, повёрнута на −2°, старая повреждённая фотография. Под ней подпись label: `ИСХОДНИК`

Правая: чуть выше, повёрнута на +2°, та же фотография восстановленная. Под ней точка `gold2` и подпись label: `В ДВИЖЕНИИ`

Пока используй фото-заглушки — чёрно-белый портрет пожилой женщины.

В левом нижнем углу колонки — подпись label: `ОДИН КАДР · 5 СЕКУНД ВИДЕО`

В правом верхнем углу — уголок из двух линий 1px `rule` длиной 32px, как метка кадрирования.

Футер

Фон `bg`, сверху граница 1px `rule`, padding 64px.

Слева: лого «Live Era», под ним строка body: «Нейросеть для оживления фотографий — онлайн, на русском, без VPN.»

Справа четыре колонки ссылок-заглушек, заголовки колонок в стиле label:

`СЦЕНАРИИ` — Старое фото, Видео из фото, Фото питомца, Оживить рисунок

`НЕЙРОСЕТИ` — Kling 3.0, Sora 2, Veo 3.1, Seedance 2.0

`СЕРВИС` — Примеры, Цены, Блог, FAQ

`ДОКУМЕНТЫ` — Оферта, Возвраты, Персональные данные, Cookie

Снизу делитель `rule2` и строка: слева `© 2026 LIVE ERA` в стиле label, справа почта.

Обязательно

Адаптив до 360px.

Видимый фокус на всех интерактивных элементах — обводка 2px `gold2`.

Никаких анимаций сверх описанных.
